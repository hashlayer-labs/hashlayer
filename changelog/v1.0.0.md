# v1.0.0

Initial public release of the HashLayer subnet package.

## Included

- `hashlayer.core` — shared constants, pool clients, pricing, storage, loyalty helpers
- `hashlayer.validator` — Bittensor validator for SHA256d (BTC) hashrate scoring and weights (including loyalty coefficient C)

## Miner

Mining is hardware → stratum (hotkey as username). No Python miner process is required or shipped in this repository.
